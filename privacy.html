이 방침은 개인용 Google Drive 동기화 도구 papers-sync와 이를 소개하는 정적 웹사이트에 적용됩니다.

접근하는 데이터

동기화에 필요한 파일 내용, 파일명, 폴더 구조, 파일 식별자, 크기, 수정 시각, 체크섬 등 Google Drive 파일 메타데이터에 접근합니다. Google 로그인 과정에서 발급되는 접근 토큰과 갱신 토큰은 동기화 프로그램이 Google API에 인증하는 데 사용합니다.

기존 Drive 파일의 양방향 동기화를 위해 전체 Drive 접근 범위인 https://www.googleapis.com/auth/drive를 요청합니다. 프로그램은 설정된 폴더를 대상으로 동기화를 수행합니다.

사용 목적

데이터는 Google Drive와 사용자가 지정한 컴퓨터 사이의 파일 동기화, 변경 감지, 무결성 확인, 충돌 처리와 백업에 사용합니다. 파일 추가, 변경, 이동 및 삭제가 반영될 수 있습니다. Google 사용자 데이터를 광고, 판매 또는 AI 모델 학습에 사용하지 않습니다.

저장 및 보안

파일 사본과 백업은 사용자의 컴퓨터 및 Google Drive에 저장됩니다. 인증 토큰은 동기화 대상 폴더 밖의 비공개 로컬 설정 파일에 저장합니다. 동기화 기록과 상태에는 파일명 등 메타데이터가 포함될 수 있으며 로컬 컴퓨터에 저장됩니다. Google API와의 통신에는 HTTPS를 사용합니다.

이 웹사이트는 Google 인증 토큰이나 Drive 파일을 수신·저장하지 않으며, 별도의 동기화 서버를 운영하지 않습니다. 로컬 데이터의 보호는 운영체제 계정 권한과 컴퓨터 보안 설정에도 영향을 받습니다.

데이터 공유

동기화에 필요한 파일과 요청은 Google Drive와 사용자의 컴퓨터 사이에서 전달됩니다. 운영자는 동기화 데이터를 광고 사업자에게 제공하거나 판매하지 않습니다. 법적으로 요구되는 경우를 제외하고 해당 데이터를 다른 목적으로 제3자에게 제공하지 않습니다.

안내 웹사이트는 GitHub Pages에서 호스팅됩니다. GitHub는 사이트 제공과 보안을 위해 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 사항은 GitHub 개인정보처리방침을 참조하세요. 이 사이트에는 별도의 분석 스크립트, 광고, 쿠키 설정 기능을 추가하지 않았습니다.

보관 및 삭제

파일, 백업 및 동기화 기록은 사용자가 직접 삭제할 때까지 해당 컴퓨터 또는 Google Drive에 남을 수 있습니다. 동기화 중 파일을 삭제하면 다른 쪽에도 반영될 수 있으며, 백업 사본은 별도로 남을 수 있습니다. 데이터 삭제 시 양쪽 저장소와 백업을 확인해야 합니다.

사용자는 동기화 프로그램을 중지하고 Google 계정의 연결 관리에서 앱 접근 권한을 철회할 수 있습니다. 철회는 이후 접근을 중지하며 기존에 저장된 파일 사본이나 백업을 자동으로 삭제하지 않습니다. 로컬 인증 설정을 삭제하면 저장된 토큰을 제거할 수 있습니다.

Google 사용자 데이터 정책

papers-sync가 Google API에서 받은 정보를 사용하거나 다른 앱으로 이전하는 경우 Google API Services User Data Policy 및 그 안의 Limited Use 요구사항을 준수합니다.
